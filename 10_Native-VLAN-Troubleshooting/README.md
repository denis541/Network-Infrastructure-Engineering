## Objective

Deliberately introduce a native VLAN mismatch on a trunk link between two switches, observe the CDP warning generated by the misconfiguration, understand the security implications, and resolve the mismatch by aligning native VLANs on both sides.

---

## Topology

```
[SW1] ---trunk--- [SW2]
Fa0/1             Fa0/1
```

---

## Configuration

### Step 1 — Configure Trunk Links

```bash
# On SW1
SW1(config)# interface fa0/1
SW1(config-if)# switchport mode trunk

# On SW2
SW2(config)# interface fa0/1
SW2(config-if)# switchport mode trunk
```

### Step 2 — Verify Default Native VLAN

```bash
SW1# show interfaces fa0/1 switchport
SW2# show interfaces fa0/1 switchport
```

Both switches show `Trunking Native Mode VLAN: 1 (default)` — trunk is clean.

### Step 3 — Introduce the Mismatch

```bash
# Change native VLAN on SW1 only
SW1(config)# interface fa0/1
SW1(config-if)# switchport trunk native vlan 99
```

SW2 still has native VLAN 1. The mismatch is now active.

### Step 4 — Fix the Mismatch

```bash
# Match native VLAN on SW2
SW2(config)# interface fa0/1
SW2(config-if)# switchport trunk native vlan 99
```

Both sides now agree on native VLAN 99. Mismatch resolved.

---

## Verification Commands

```bash
# Check native VLAN on both sides
SW1# show interfaces fa0/1 switchport
SW2# show interfaces fa0/1 switchport

# Check trunk status
SW1# show interfaces trunk
```

### Expected Output After Fix

```
Trunking Native Mode VLAN: 99
Administrative Mode: trunk
Operational Mode: trunk
```

## Concepts Covered

- Native VLAN — the VLAN assigned to untagged traffic on a trunk link
- CDP (Cisco Discovery Protocol) — detects and warns about native VLAN mismatches between directly connected Cisco devices
- Native VLAN mismatch — both sides of a trunk must have the same native VLAN or untagged traffic lands in the wrong VLAN
- VLAN hopping attack — a security exploit that takes advantage of native VLAN mismatches to send traffic across VLAN boundaries
- Trunking mode vs native VLAN — two independent settings on a trunk port
